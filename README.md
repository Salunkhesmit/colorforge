# ColorForge — Gradient Generator 🎨

**ColorForge** is an interactive gradient design studio created as a hands-on practice project while learning JavaScript.

## ✨ About the Project

ColorForge started as a way to practice JavaScript, experiment with web development, and explore the integration of 3D visuals into a web application.

The project is primarily for learning and practice, exploring frontend development concepts, and testing creative UI interactions and 3D integration.

### Key Features

- Multiple gradient types: Linear, Radial, and Conic
- Interactive gradient style gallery
- Advanced color stops and hard-stop effects
- Custom gradient angles, directions, and positions
- Live CSS preview and gradient customization
- Gradient presets, randomization, and history controls
- Favorites and gradient settings management
- CSS and image export
- AI Studio with local gradient-generation and color exploration tools
- Interactive 3D visuals and preview features

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Anime.js
- Three.js
