# ColorForge — Gradient Generator 🎨

**ColorForge** is a modern, interactive gradient design studio for creating, customizing, and exploring beautiful CSS gradients.

It combines advanced gradient controls, a visually immersive interface, and creative tools to make gradient design more intuitive and enjoyable.

## ✨ About the Project

ColorForge allows users to experiment with different gradient styles, customize colors and color stops, adjust gradient directions, and explore creative color combinations.

### Key Features

- Multiple gradient types: Linear, Radial, and Conic
- Interactive gradient style gallery
- Advanced color stops and hard-stop effects
- Custom gradient angles, directions, and positions
- Live CSS preview and gradient customization
- Gradient presets, randomization, and history controls
- Favorites and gradient settings management
- CSS and image export
- AI Studio with local gradient-generation and color exploration tools
- Interactive 3D visuals and preview features

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Anime.js
- Three.js
